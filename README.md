# Kotlin Mobile Developer Portfolio

A distinctive, responsive portfolio for a Kotlin-focused mobile engineer. The site presents selected Android work, experience, technical writing, and a Netlify-powered contact form in a single cohesive visual system.

## Technology

- TanStack Start and React 19
- TypeScript and Tailwind CSS v4
- Content Collections for Markdown-driven projects, experience, and notes
- Netlify Forms for contact submissions
- Lucide icons

## Local development

Install dependencies and start the Netlify development environment:

```bash
pnpm install
netlify dev --port 8889
```

Content can be personalized in `content/`. Global visual styling lives in `src/styles.css`, while page routes live in `src/routes/`.
